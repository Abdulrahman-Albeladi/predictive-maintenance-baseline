# Data

Source: NASA C-MAPSS Jet Engine Simulated Data: https://data.nasa.gov/dataset/cmapss-jet-engine-simulated-data

NASA source files are downloaded or supplied locally and are not committed to the repository.

## Repository policy

Do not commit:

- raw or processed datasets;
- database files;
- generated Parquet, CSV, Excel, Power BI, or model artifacts;
- API keys, tokens, cookies, or credential files;
- private, licensed, or personally identifiable data.

Use the notebook's configuration cell to point to a local file or cache. If a public dataset is downloaded automatically, follow its source terms and citation guidance.
